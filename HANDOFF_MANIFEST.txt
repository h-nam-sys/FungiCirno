FungiCirno — completed application architecture + verification handoff

Included:

- Shared Ultralytics YOLOv8-seg runtime and normalized Prediction pipeline.

- Final architecture, integration contract, acceptance checklist and focused member/AI handoffs.

Intentionally not included:
- M18K checkpoint weights, Charisis/MushR model weights or other trained weights.
- Raw datasets, local captures/masks, SQLite database or private machine data.

Validation boundary:
The application implementation and integration workflow are included. Trained oyster target checkpoints, target-domain evaluation, full-model CPU/AMD execution evidence, tracking ID evaluation, camera calibration validation and a complete review/fine-tune/rollback execution are not included and must not be claimed until run. Members are assigned to verify these external-data and target-hardware dependencies and submit bounded fixes only.
