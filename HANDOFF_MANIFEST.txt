FungiCirno — Complete Implementation Handoff
Release package: 2026-11-11

Included:
- Full Streamlit application and Python source package
- SQLite schema and additive migrations (database is created on first launch)
- Ultralytics YOLO-seg model adapter and legacy TorchVision adapter
- CPU and AMD DirectML selectable inference backends

Intentionally excluded:
- M18K best.pt weights and any other trained weights
- M18K raw images/annotations and side-view datasets
- Local SQLite databases, captures, masks and personal machine paths
- Candidate checkpoints or exported model bundles

Important:
This is an integrated implementation handoff, not a claim of end-to-end validation. Members must run and repair their assigned subsystems. Full Ultralytics YOLO inference on AMD DirectML, 12 GB RAM behavior, side-view transfer performance, sequence-level tracking accuracy, physical calibration, and incremental retraining/rollback remain to be demonstrated with actual logs and evidence.
